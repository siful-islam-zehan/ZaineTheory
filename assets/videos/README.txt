HERO SECTION VIDEO INSTRUCTIONS
================================

Place your hero section video file in this folder with the name:
  hero-video.mp4

The website is already wired to automatically load and play:
  assets/videos/hero-video.mp4

Supported formats: MP4 (H.264), WebM.
The video is configured to:
  - Autoplay smoothly
  - Loop continuously
  - Run muted (browser policy compliant)
  - Fit responsively inside the 3D frame in the Hero section
